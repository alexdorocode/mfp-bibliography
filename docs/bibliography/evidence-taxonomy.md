# Evidence Taxonomy (Working Definitions)

These are operational definitions for repository workflows and remain subject to scholarly review.

- **Moonlighting protein**: a protein described as performing multiple distinct biological functions under documented contexts.
- **Multifunctional protein**: a broader working category for proteins associated with more than one function; this does not automatically imply the same evidence standard across sources.
- **Extreme multifunctional protein**: a provisional category for records suggesting unusually broad functional range; criteria remain to be formalized.
- **Experimental curation**: evidence grounded in experimentally reported observations.
- **Literature curation**: evidence extracted from curated literature interpretations.
- **Computational prediction**: evidence generated by computational inference that is not treated as experimentally validated by default.
- **Source record**: one entry from a specific source artifact with source-local identifiers and locators.
- **Evidence claim**: an interpreted statement derived from one or more source records.
- **Benchmark eligibility**: a separate assignment indicating whether/why a record can be used in a future benchmark context.
