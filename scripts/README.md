# Scripts

- `validate_repository.py`: checks scaffold structure, manifest header, and schema validity.
- `build_manifest.py`: safe skeleton for manifest generation workflow.
- `normalize_source_records.py`: placeholder CLI for future source adapters.
- `profile_source.py`: read-only local profiling command for source artifacts. Emits structured JSON output without network calls or mutations to `data/raw/`. Fails explicitly for malformed input.
